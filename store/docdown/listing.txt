NAME
Docdown – Web page to Markdown

SUMMARY (max 132 chars — same as the manifest description)
Copy any web page, doc or selection as clean, LLM-ready Markdown: code languages kept, links absolute, front matter. 100% local.

CATEGORY
Developer Tools

DESCRIPTION
(No product or brand names here: the first submission was rejected for "excessive keywords" — violation
"Yellow Argon" — because it listed AI tools, note apps and documentation sites by name.)

Turn any documentation page, article or text selection into clean Markdown you can paste into an AI assistant, a notes app or your own docs, without the clutter that plain copy and paste brings along.

Built for developers
• Code blocks keep their language (```js, ```python, ```yaml …) and come out clean: no line numbers, no "Copy" buttons, no shell prompts
• Reads code that modern documentation sites place inside web components (shadow DOM)
• Note, tip and warning boxes become Markdown callouts: > [!NOTE], > [!WARNING]
• Tables become Markdown tables; links and images become full URLs
• Heading anchors, edit links and other page clutter are removed

Three ways to clip
• Article: the main content, detected automatically
• Whole page: everything visible
• Selection: only the part you selected (a selection inside a code block stays a code block)

Before you copy
• Preview the result or edit the Markdown
• Approximate token count, so you know how much text you are pasting into an AI assistant
• Front matter: none, basic (title, source, date) or your own template with placeholders such as {title}, {url} and {date}
• Copy, Copy as prompt (with the source link) or Download .md

Quick to reach
• Toolbar button, right-click menu or Alt+Shift+M

Private by design
Docdown only reads the tab you click it on, runs entirely in your browser, sends nothing anywhere and contains no remote code. Settings are stored with Chrome sync storage only.

PERMISSION JUSTIFICATION (Privacy tab)
Single purpose: Convert the current web page, its main article or the selected part into Markdown text for the user to copy or download.
activeTab: Read the page the user explicitly clipped (toolbar button, keyboard shortcut or right-click menu), only at that moment.
scripting: Run the bundled conversion script in that tab to turn its content into Markdown.
contextMenus: Add "Clip selection to Markdown" and "Clip page to Markdown" to the right-click menu.
storage: Save the user's settings (default mode, front matter template, images on/off).
Remote code: No — all libraries are bundled in the package.
Data usage: No user data is collected or transmitted.

MÔ TẢ TIẾNG VIỆT (nếu thêm ngôn ngữ vi cho listing)

Biến trang tài liệu, bài viết hay đoạn bạn chọn thành Markdown sạch để dán vào trợ lý AI, ứng dụng ghi chú hay tài liệu của bạn, không kèm rác như khi sao chép thông thường.

• Khối code giữ đúng ngôn ngữ, bỏ số dòng, nút "Copy", dấu nhắc lệnh
• Đọc được code nằm trong web component (shadow DOM)
• Hộp ghi chú, mẹo, cảnh báo → khối callout Markdown > [!NOTE], > [!WARNING]
• Bảng thành bảng Markdown; link và ảnh thành địa chỉ đầy đủ
• 3 chế độ: Bài viết · Cả trang · Đoạn chọn
• Xem trước, sửa trước khi chép, ước tính số token
• Front matter: không, cơ bản, hoặc mẫu riêng của bạn
• Sao chép, Chép làm prompt (kèm link nguồn), hoặc Tải .md
• Nút trên thanh công cụ, menu chuột phải, hoặc Alt+Shift+M
• Riêng tư: chỉ đọc tab bạn bấm, chạy hoàn toàn trên máy, không gửi dữ liệu đi đâu
